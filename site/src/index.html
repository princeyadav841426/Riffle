Quick Look stops at the folder.

Press Space on a photo and you see the photo. Press Space on a folder and you see an icon. To find out what's inside, you open it, look, close it and go back.

Riffle replaces the icon with the folder's contents, so one keypress answers "what's in here, and how big is it?"

Open it once

macOS says it can't verify Riffle. Click Done, then System Settings → Privacy & Security → Open Anyway. Or run this in Terminal:

xattr -dr com.apple.quarantine /Applications/Riffle.app

When Riffle shows a green tick, close it. Select any folder in Finder and press Space. There's no app to keep running.

Questions

Is Riffle really free?
Yes. There's no trial, no Pro version and no in-app purchase. Riffle is open source under the MIT license, so the code is on GitHub and anyone can build it themselves.
Why does macOS say it can't verify Riffle?
Apple shows that for apps that aren't distributed through the App Store or notarized with a paid developer account. Click Done, then open System Settings → Privacy & Security and click Open Anyway. You only do this once.
Does Riffle read or upload my files?
Riffle runs inside Apple's Quick Look sandbox with read-only access to what you preview. It has no account, no analytics and no tracking, and it doesn't send your files anywhere. You can check the code on GitHub.
Which Macs does it work on?
Macs running macOS 14 Sonoma or later. Riffle is a universal app, so it runs natively on Apple silicon and Intel.
Can it preview ZIP or RAR files?
Not yet. If you need to look inside archives without unpacking them, Folder Preview by Anybox does that well.
I press Space and still see the folder icon.
Open Riffle from Applications and look for the green tick. If it says Riffle is off, click Extension Settings and switch it on under Quick Look. If another folder previewer such as PeekX is installed, remove it, because only one app can answer Space for folders.
How do I uninstall it?
Drag Riffle from Applications to the Trash. Quick Look goes back to showing folder icons.
Who makes Riffle?
Aignix, a video studio. We built Riffle for our own editing folders and give it away. It started as a fork of PeekX by ALTIC, an MIT-licensed project, and has since gained a rebuilt preview pane, thumbnails, details and offline Markdown.
